48 + 13 = 61 48 - 13 = 35 48 * 13 = 624 48 / 13 = 3 48 % 13 = 9

03 Unary operators Unary

Create a class named UnaryOperators.

Inside main, declare int x = 10; and boolean isActive = false;.

Demonstrate each unary operator and print the result:

  1. Unary plus: +x
  2. Unary minus: -x
  3. Pre-increment: ++x (print the value of x after)
  4. Post-increment: x++ (print the expression value, then print x after)
  5. Pre-decrement: --x (print the value of x after)
  6. Post-decrement: x-- (print the expression value, then print x after)
  7. Logical NOT: !isActive
Unary plus: +10 = 10 Unary minus: -10 = -10 Pre-increment: ++x = 11, x is now 11 Post-increment: x++ = 11, x is now 12 Pre-decrement: --x = 11, x is now 11 Post-decrement: x-- = 11, x is now 10 NOT isActive: true

05 Logical operators Logical

Create a class named LogicalOperators.

Inside main, declare:

  • boolean hasID = true;
  • boolean hasTicket = false;
  • boolean isVIP = true;

Evaluate and print the following expressions with labels:

  1. hasID && hasTicket — "Can enter (needs both ID and ticket)"
  2. hasID || hasTicket — "Has at least one document"
  3. !hasTicket — "Missing ticket"
  4. (hasID && hasTicket) || isVIP — "Allowed entry (has both OR is VIP)"
  5. !(hasID && isVIP) — "NOT (has ID and is VIP)"
hasID && hasTicket: false hasID || hasTicket: true !hasTicket: true (hasID && hasTicket) || isVIP: true !(hasID && isVIP): false
06 Bitwise operators Bitwise

Create a class named BitwiseOperators.

Inside main, declare:

  • int a = 12; (binary: 1100)
  • int b = 10; (binary: 1010)

Compute and print the result of each bitwise operation, showing the decimal result:

  1. AND: a & b
  2. OR: a | b
  3. XOR: a ^ b
  4. NOT: ~a
  5. Left shift: a << 2
  6. Right shift: a >> 2
12 & 10 = 8 12 | 10 = 14 12 ^ 10 = 6 ~12 = -13 12 << 2 = 48 12 >> 2 = 3

09 Operator precedence Arithmetic

Create a class named OperatorPrecedence.

Inside main, evaluate and print the result of each expression. Do NOT simplify — let Java compute them as written:

  1. int r1 = 10 + 5 * 3;
  2. int r2 = (10 + 5) * 3;
  3. int r3 = 20 - 4 / 2 + 1;
  4. int r4 = 20 - 4 % 3 + 2;
  5. boolean r5 = 5 > 3 && 10 < 20;
  6. boolean r6 = 5 > 3 || 10 > 20;
10 + 5 * 3 = 25 (10 + 5) * 3 = 45 20 - 4 / 2 + 1 = 19 20 - 4 % 3 + 2 = 21 5 > 3 && 10 < 20 = true 5 > 3 || 10 > 20 = true
10 Mini calculator — Putting it all together Arithmetic Ternary Constants

Create a class named MiniCalculator.

Declare a static final constant:

  • static final double DISCOUNT_RATE = 0.10;

Inside main, declare:

  • double itemPrice = 2500.00;
  • int quantity = 3;

Compute the following using local variables:

  1. subtotal — item price multiplied by quantity
  2. discount — apply DISCOUNT_RATE to subtotal
  3. total — subtotal minus discount
  4. Use the ternary operator: if total > 5000, set String note to "Premium purchase", otherwise "Standard purchase"
  5. Use relational operators: boolean isExpensive = total > 5000;
Item price: 2500.0 Quantity: 3 Subtotal: 7500.0 Discount (10%): 750.0 Total: 6750.0 Note: Premium purchase Is expensive: true
