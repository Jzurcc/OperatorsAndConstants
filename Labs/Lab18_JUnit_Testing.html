Quick reference
TopicKey syntax / annotation
Test method@Test void myTest() { }
assertEqualsassertEquals(expected, actual) — checks two values are equal
assertTrue / assertFalseassertTrue(condition) — checks a boolean condition
assertNull / assertNotNullassertNotNull(object) — checks object is (not) null
assertThrowsassertThrows(Exception.class, () -> { ... }) — verifies an exception is thrown
assertAllassertAll(() -> assertEquals(...), () -> assertTrue(...)) — groups multiple assertions
@BeforeEachRuns before every test method — use for setup (e.g. creating objects)
@AfterEachRuns after every test method — use for teardown / cleanup
@BeforeAllstatic method — runs once before all tests in the class
@AfterAllstatic method — runs once after all tests in the class
@ParameterizedTestRuns the same test with multiple inputs — combine with @ValueSource or @CsvSource
@DisplayName@DisplayName("human-readable label") — shown in the test report
@DisabledSkips a test method (marks it as ignored)
Project setup

Follow these steps exactly:

  1. Open IntelliJ IDEA.
  2. Create a new Maven project named JUnitTesting.
  3. Add the JUnit 5 dependency to your pom.xml:
    org.junit.jupiter:junit-jupiter:5.10.2
    Also add maven-surefire-plugin version 3.2.5 so Maven can run your tests.
  4. Inside src/main/java, create two packages:
    com.school.app
    com.school.service
  5. Inside src/test/java, mirror the same packages for your test classes.
  6. Each test class must import from org.junit.jupiter.api.* and org.junit.jupiter.params.* where needed.
Important: Follow class names, package names, and test method names exactly as written. Incorrect names will be marked as incomplete.
