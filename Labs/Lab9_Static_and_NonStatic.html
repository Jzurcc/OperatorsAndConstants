Static & Non-Static

This exercise covers the difference between static (belongs to the class) and non-static / instance (belongs to the object) for both variables and methods. You will observe how they behave differently in memory, access, and usage. Follow every instruction carefully.

Topics
Static vs Non-Static
Quick reference
Static Non-static (instance)
Variable One copy shared by all objects. Accessed via ClassName.variable. Each object has its own copy. Accessed via object.variable.
Method Called without an object: ClassName.method(). Cannot access instance members directly. Called on an object: object.method(). Can access both static and instance members.
Memory Loaded once when the class is loaded. Created each time new is called.
Use when Value or behavior is shared (counters, utility methods, constants). Value or behavior is unique per object.

01 Static variable — Shared counter Static variable

Create a class named Counter with:

  • static int count = 0; — shared across all objects
  • String label; — unique to each object (non-static)

Create a constructor that accepts label and increments count by 1.

Create TestCounter. Create 4 Counter objects with different labels. After each creation, print Counter.count.

Created: Alpha — Count: 1 Created: Beta — Count: 2 Created: Gamma — Count: 3 Created: Delta — Count: 4 Accessing count via class name: Counter.count = 4 Accessing count via object: 4 (same value — it's shared)
Key learning: All 4 objects share the same count variable. Changing it through one object changes it for all. Access it via Counter.count (preferred) or via any object.

--- Before change --- Alice, Age 20, GPA: 3.5 Bob, Age 21, GPA: 2.8 Charlie, Age 19, GPA: 3.9 Changing Bob's GPA to 3.1... --- After change --- Alice, Age 20, GPA: 3.5 Bob, Age 21, GPA: 3.1 Charlie, Age 19, GPA: 3.9
Key learning: Non-static fields belong to each individual object. Changing Bob's GPA does not affect Alice or Charlie — each object has its own memory.
03 Static method — Utility class Static method

Create a class named MathHelper with only static methods (no instance fields, no constructor needed):

  • public static int add(int a, int b)
  • public static int subtract(int a, int b)
  • public static int multiply(int a, int b)
  • public static double divide(int a, int b) — return 0 if b is 0
  • public static int max(int a, int b)
  • public static int min(int a, int b)

Create TestMathHelper. Call all methods without creating an object — use MathHelper.add(10, 5) directly.

MathHelper.add(10, 5) = 15 MathHelper.subtract(10, 5) = 5 MathHelper.multiply(10, 5) = 50 MathHelper.divide(10, 5) = 2.0 MathHelper.divide(10, 0) = 0.0 MathHelper.max(10, 5) = 10 MathHelper.min(10, 5) = 5
Key learning: Static methods belong to the class, not to objects. You call them using the class name directly. Utility/helper classes often contain only static methods — Java's Math class works this way.

05 Access rules — What can access what Error demo Mixed

Create a class named AccessRules with:

  • static String className = "AccessRules";
  • String instanceName = "Object-Level";

Add four methods:

  • public static void staticMethod() — prints className. Try to print instanceName — it will cause a compile error.
  • public void instanceMethod() — prints both className and instanceName (this works because instance methods can access static members).
  • public static void callInstanceMethod() — try to call instanceMethod() directly — compile error. Write the error as a comment.
  • public void callStaticMethod() — call staticMethod() directly — this works.

Create TestAccessRules. Demonstrate what works and what doesn't.

--- Static method accessing static variable --- Class name: AccessRules --- Instance method accessing both --- Class name: AccessRules Instance name: Object-Level --- Instance method calling static method --- Class name: AccessRules
// Inside staticMethod(): instanceName → ERROR: non-static variable instanceName cannot be referenced from a static context // Inside callInstanceMethod(): instanceMethod() → ERROR: non-static method instanceMethod() cannot be referenced from a static context
Key learning:
✓ Static can access static.
✓ Instance can access static.
✓ Instance can access instance.
✗ Static cannot access instance (no object exists yet).

10 Putting it all together — Classroom manager Mixed

Create a class named Classroom that uses both static and non-static members together.

Static members (school-wide):

  • static String schoolName = "Greenfield Academy";
  • static int totalClassrooms = 0;
  • static int totalStudentsEnrolled = 0;
  • static final int MAX_PER_CLASS = 5;
  • public static void displaySchoolSummary() — prints school name, total classrooms, total students

Non-static members (per classroom):

  • int classroomId;
  • String teacher;
  • String subject;
  • String[] students; — max 5
  • int studentCount;

Create a constructor that accepts teacher and subject, auto-assigns classroomId from totalClassrooms, and initializes the array.

Add non-static methods:

  • public void enroll(String name) — adds student if not full, increments both studentCount and totalStudentsEnrolled
  • public boolean isFull()
  • public void displayClassInfo()

Create TestClassroom. Create 2 classrooms, enroll students, display each, then display the school-wide summary.

======================================== Classroom #1 — Java Programming ======================================== Teacher: Mr. Garcia Students: 1. Alice 2. Bob 3. Charlie Enrolled: 3/5 | Full: false ======================================== Classroom #2 — Data Structures ======================================== Teacher: Ms. Reyes Students: 1. Diana 2. Edward 3. Error: Classroom is full. ======================================== SCHOOL SUMMARY (static) ======================================== School: Greenfield Academy Total classrooms: 2 Total students enrolled: 8 ========================================
Key takeaway: Static members track school-wide data (total classrooms, total students) shared across all objects. Non-static members track per-classroom data (teacher, student list). Both work together — the enroll() method updates instance data and static data in the same call.
