Collections — List, Set & Map

This exercise covers the three core Java Collection types: List (ordered, allows duplicates), Set (unordered, no duplicates), and Map (key-value pairs). You will use ArrayList, LinkedList, HashSet, TreeSet, HashMap, TreeMap, and practice iterating, sorting, and combining them. Follow every instruction carefully.

Quick reference
Interface Implementation Ordered? Duplicates? Key feature
List ArrayList Yes (by index) Yes Fast random access, most commonly used
LinkedList Yes (by index) Yes Fast insert/remove at beginning or middle
Set HashSet No No Fastest lookups, no ordering
TreeSet Yes (sorted) No Automatically sorted
Map HashMap No Keys: No / Values: Yes Fastest key-value lookups
TreeMap Yes (by key) Keys: No / Values: Yes Keys automatically sorted

01 ArrayList basics List

Create a class named ArrayListBasics.

Inside main, create an ArrayList<String> named fruits and demonstrate the following operations:

  1. Add 5 fruits: "Mango", "Apple", "Banana", "Cherry", "Apple" (note the duplicate).
  2. Print the list and its size.
  3. Access element at index 2 using get().
  4. Update index 1 to "Avocado" using set().
  5. Remove "Cherry" using remove(Object).
  6. Check if "Mango" exists using contains().
  7. Find the index of "Banana" using indexOf().
  8. Sort the list using Collections.sort().
  9. Print the final list.
Original: [Mango, Apple, Banana, Cherry, Apple] Size: 5 Element at index 2: Banana After set(1, "Avocado"): [Mango, Avocado, Banana, Cherry, Apple] After remove("Cherry"): [Mango, Avocado, Banana, Apple] Contains "Mango"? true Index of "Banana": 2 After sort: [Apple, Avocado, Banana, Mango]
Key learning: ArrayList maintains insertion order, allows duplicates, and provides index-based access. Unlike arrays, it grows and shrinks dynamically.
02 LinkedList — Queue-like behavior List

Create a class named LinkedListDemo.

Inside main, create a LinkedList<String> named queue and demonstrate:

  1. Add elements using add(): "Task A", "Task B", "Task C".
  2. Add to the front using addFirst("Urgent Task").
  3. Add to the end using addLast("Low Priority").
  4. Print the list.
  5. Peek at the first element using getFirst() (does not remove).
  6. Peek at the last element using getLast().
  7. Remove the first element using removeFirst() — simulates dequeue.
  8. Remove the last element using removeLast().
  9. Print the final list.
Queue: [Urgent Task, Task A, Task B, Task C, Low Priority] Size: 5 First: Urgent Task Last: Low Priority Removed first: Urgent Task Removed last: Low Priority Final queue: [Task A, Task B, Task C]
Key learning: LinkedList implements both List and Deque interfaces. Its addFirst(), addLast(), removeFirst(), removeLast() make it ideal for queue and stack behavior.
03 List iteration — Four ways List Iteration

Create a class named ListIteration.

Inside main, create an ArrayList<Integer> with values: 10, 20, 30, 40, 50.

Print the list using four different methods:

  1. For loop with index: for (int i = 0; i < list.size(); i++)
  2. Enhanced for loop: for (int num : list)
  3. Iterator: Iterator<Integer> it = list.iterator(); with while (it.hasNext())
  4. forEach with lambda: list.forEach(num -> System.out.println(num));

Then demonstrate removing while iterating: use an Iterator to remove all even numbers. Print the result.

--- 1. For loop --- Index 0: 10 Index 1: 20 Index 2: 30 Index 3: 40 Index 4: 50 --- 2. Enhanced for loop --- 10 20 30 40 50 --- 3. Iterator --- 10 20 30 40 50 --- 4. forEach lambda --- 10 20 30 40 50 --- Removing even numbers with Iterator --- Before: [10, 20, 30, 40, 50] After: [30, 50]
Key learning: Use Iterator.remove() to safely remove elements during iteration. Using list.remove() inside a for-each loop causes ConcurrentModificationException.

09 List vs Set vs Map — Side by side List Set Map

Create a class named ListSetMapCompare.

Inside main, start with this array of names (with duplicates):

  • String[] names = {"Alice", "Bob", "Charlie", "Alice", "Diana", "Bob", "Edward", "Charlie"};

Do the following:

  1. Add all names to an ArrayList<String>. Print it — shows duplicates, preserves order.
  2. Add all names to a HashSet<String>. Print it — duplicates removed, no guaranteed order.
  3. Add all names to a TreeSet<String>. Print it — duplicates removed, sorted.
  4. Count the frequency of each name using a HashMap<String, Integer>. For each name, use getOrDefault(name, 0) + 1 to count occurrences. Print the frequency map.
  5. Find the most frequent name by iterating through the map.
--- ArrayList (ordered, with duplicates) --- [Alice, Bob, Charlie, Alice, Diana, Bob, Edward, Charlie] Size: 8 --- HashSet (no duplicates, unordered) --- [Bob, Diana, Alice, Charlie, Edward] Size: 5 --- TreeSet (no duplicates, sorted) --- [Alice, Bob, Charlie, Diana, Edward] Size: 5 --- HashMap (frequency count) --- Alice: 2 Bob: 2 Charlie: 2 Diana: 1 Edward: 1 Most frequent: Alice (2 times)
Key learning: Same data, different collection = different behavior. List keeps everything as-is. Set removes duplicates. Map lets you associate data (like counting occurrences). Choose the right collection for the job.
