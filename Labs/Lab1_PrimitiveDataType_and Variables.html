Primitive Data Types & Variable Types

This exercise will test your understanding of Java's eight primitive data types (byte, short, int, long, float, double, char, boolean) and two types of variables (static and local). Follow every instruction carefully.

Project setup

Follow these steps exactly:

  1. Open your IDE (IntelliJ IDEA, Eclipse, or VS Code).
  2. Create a new Java project named PrimitiveDataTypes.
  3. Inside the src folder, create a package named com.school.basics.
  4. For each exercise below, create the class file specified inside the com.school.basics package.
  5. Each class must have a public static void main(String[] args) method that demonstrates the required output.
Important: Follow class names, package names, and file names exactly as written. Incorrect names will be marked as incomplete.

Exercises
01 Integer primitive types Local variables

Create a class named Exercise01.

Inside main, declare one local variable for each integer primitive type and assign the following values:

  • byte myByte = 120
  • short myShort = 30000
  • int myInt = 1500000
  • long myLong = 9876543210L

Print each variable on a separate line with its type label.

byte value: 120 short value: 30000 int value: 1500000 long value: 9876543210
02 Decimal primitive types Local variables

Create a class named Exercise02.

Inside main, declare:

  • A float local variable named pi with value 3.1416f
  • A double local variable named gravity with value 9.80665

Print both with their labels. Then compute the sum of pi and gravity, store it in a double variable named sum, and print it.

float pi: 3.1416 double gravity: 9.80665 sum: 12.94825
03 Characters and booleans Local variables

Create a class named Exercise03.

Inside main, declare:

  • A char variable named initial with the first letter of your first name.
  • A char variable named grade with value 'A'.
  • A boolean variable named isPassing set to true.
  • A boolean variable named isAbsent set to false.

Print each on its own line with labels.

initial: J grade: A isPassing: true isAbsent: false

(Your initial will differ based on your name.)

07 Arithmetic with local variables Local variables

Create a class named Exercise07.

Inside main, declare:

  • int a = 25;
  • int b = 7;

Compute and print the result of each operation, storing each result in a new local variable:

  • Addition (a + b)
  • Subtraction (a - b)
  • Multiplication (a * b)

25 + 7 = 32 25 - 7 = 18 25 * 7 = 175 25 / 7 = 3 25 % 7 = 4
08 Type casting Local variables

Create a class named Exercise08.

Inside main, perform the following conversions using local variables:

  1. Widening (automatic): Declare int myInt = 100; then assign it to a double variable named myDouble. Print both.
  2. Narrowing (manual): Declare double price = 9.99; then cast it to an int variable named wholePrice using (int). Print both.
  3. char to int: Declare char letter = 'Z'; then store its numeric ASCII value in an int named asciiValue. Print both.
int value: 100 → double value: 100.0 double value: 9.99 → int value: 9 char value: Z → ASCII value: 90

10 Putting it all together — Student report card Static + Local

Create a class named Exercise10. This exercise combines static and local variables.

Declare the following static variables at the class level:

  • static String schoolName = "Greenfield Academy";
  • static String semester = "1st Semester, 2025-2026";
  • static char passingGrade = 'D';

Inside main, declare the following local variables:

  • String studentName — use your own name
  • int studentId = 20240001;
  • double mathGrade = 89.5;
  • double scienceGrade = 92.0;
  • double englishGrade = 85.75;
  • double average — compute the average of the three grades
  • char finalGrade — assign 'A' if average ≥ 90, 'B' if ≥ 80, 'C' if ≥ 70, otherwise 'F' (you may use if-else or simply assign the correct letter based on your computed average)
  • boolean passed — set to true if finalGrade is not 'F', otherwise false

Print a formatted report card:

============================= REPORT CARD ============================= School: Greenfield Academy Semester: 1st Semester, 2025-2026 Student: Juan Dela Cruz ID: 20240001 Math: 89.5 Science: 92.0 English: 85.75 Average: 89.08 Grade: B Passed: true =============================

(Your name and computed values will differ.)
