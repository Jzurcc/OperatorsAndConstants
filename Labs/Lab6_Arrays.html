02 Default values of arrays Declaration

Create a class named ArrayInitialization.

Inside main, declare the following arrays with only a size — do NOT assign any values:

  • int[] intArr = new int[3];
  • double[] doubleArr = new double[3];
  • boolean[] boolArr = new boolean[3];
  • char[] charArr = new char[3];
  • String[] strArr = new String[3];

Use a for loop to print every element of each array. Observe Java's default values.

--- int defaults --- intArr[0] = 0 intArr[1] = 0 intArr[2] = 0 --- double defaults --- doubleArr[0] = 0.0 doubleArr[1] = 0.0 doubleArr[2] = 0.0 --- boolean defaults --- boolArr[0] = false boolArr[1] = false boolArr[2] = false --- char defaults --- charArr[0] = charArr[1] = charArr[2] = --- String defaults --- strArr[0] = null strArr[1] = null strArr[2] = null
Key learning: Java automatically fills arrays with default values: 0 for numeric types, false for boolean, '\u0000' (blank) for char, and null for objects like String.

Create a class named ArrayReverse.

  • int[] original = {10, 20, 30, 40, 50, 60};

Do the following:

  1. Print the original array.
  2. Create a new array called reversed with the same length.
  3. Using a for loop, copy elements from original into reversed in reverse order.
  4. Print the reversed array.
Original: 10 20 30 40 50 60 Reversed: 60 50 40 30 20 10
Hint: To reverse, you can use reversed[i] = original[original.length - 1 - i]; inside your loop.
09 Sorting with Arrays.sort() Sort

Create a class named ArraySort.

At the top of your file (after the package line), add: import java.util.Arrays;

Inside main, declare:

  • int[] scores = {72, 95, 48, 81, 67, 90, 55};
  • String[] fruits = {"Mango", "Apple", "Cherry", "Banana", "Elderberry"};

Do the following:

  1. Print both arrays before sorting.
  2. Use Arrays.sort() to sort each array.
  3. Print both arrays after sorting.
  4. Use Arrays.toString() to print them in a clean format.
--- Before sorting --- Scores: [72, 95, 48, 81, 67, 90, 55] Fruits: [Mango, Apple, Cherry, Banana, Elderberry] --- After sorting --- Scores: [48, 55, 67, 72, 81, 90, 95] Fruits: [Apple, Banana, Cherry, Elderberry, Mango]
Key learning: Arrays.sort() sorts numbers in ascending order and Strings in alphabetical order. Arrays.toString() returns a nicely formatted string representation of an array.
