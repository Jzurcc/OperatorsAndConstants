Polymorphism

This exercise covers polymorphism — one of the four pillars of Object-Oriented Programming. You will practice both compile-time polymorphism (method overloading) and runtime polymorphism (method overriding), along with upcasting, downcasting, instanceof, and interface-based polymorphism. Follow every instruction carefully.

Exercises
01 Method overloading — Calculator Compile-time Overloading

Create a class named Calculator with multiple overloaded versions of the add method:

  • public int add(int a, int b)
  • public int add(int a, int b, int c)
  • public double add(double a, double b)
  • public String add(String a, String b) — concatenates the strings

Also overload a multiply method:

  • public int multiply(int a, int b)
  • public double multiply(double a, double b)

Create TestCalculator. Call every version and print the results.

add(10, 20) = 30 add(10, 20, 30) = 60 add(3.14, 2.86) = 6.0 add("Hello", " World") = Hello World multiply(5, 4) = 20 multiply(2.5, 3.0) = 7.5
Key learning: The compiler decides which add() to call based on the number and type of arguments. This is resolved at compile time — the method signature determines the match.

03 Method overriding — Animal sounds Runtime @Override

Create Animal with:

  • Field: String name;
  • A constructor.
  • Methods: public String makeSound() (returns "..."), public String getType() (returns "Animal"), public void displayInfo()

Create Dog extends Animal: override makeSound() → "Woof!", getType() → "Dog"

Create Cat extends Animal: override makeSound() → "Meow!", getType() → "Cat"

Create Bird extends Animal: override makeSound() → "Tweet!", getType() → "Bird"

Create TestAnimal. Store all in an Animal[] array and loop through to call displayInfo().

[Dog] Bantay says: Woof! [Cat] Mingming says: Meow! [Bird] Tweety says: Tweet!
Key learning: The variable type is Animal but the actual object is Dog/Cat/Bird. Java calls the overridden version at runtime — this is runtime polymorphism. One array, one loop, different behaviors.
04 Polymorphic method parameter — Shape Runtime

Create Shape with: field String color;, abstract method public double getArea(), abstract method public String getShapeName(), and a concrete public void printDetails().

Create Circle (radius), Rectangle (width, height), and Triangle (base, height) — each extending Shape and implementing the abstract methods.

In TestShape, write a static method:

  • public static void describeShape(Shape s) — accepts any Shape and calls printDetails()

Pass different shapes to the same method.

--- Passing Circle --- Shape: Circle | Color: Red | Area: 78.54 --- Passing Rectangle --- Shape: Rectangle | Color: Blue | Area: 40.00 --- Passing Triangle --- Shape: Triangle | Color: Green | Area: 25.00
Key learning: The method describeShape(Shape s) accepts the parent type as a parameter. You can pass any child (Circle, Rectangle, Triangle) and Java will call the correct overridden methods. This is a powerful use of polymorphism — write one method that works for all subtypes.
05 Upcasting and downcasting — Vehicle Casting instanceof

Create Vehicle with: fields String brand;, int speed;, method public void drive(), method public void displayInfo().

Create Car extends Vehicle: field int doors;, override drive(), new method public void openTrunk().

Create Motorcycle extends Vehicle: field boolean hasSidecar;, override drive(), new method public void wheelie().

Create Truck extends Vehicle: field double cargoTons;, override drive(), new method public void loadCargo().

Create TestCasting. Demonstrate:

  1. Upcasting (automatic): Vehicle v = new Car(...); — call drive() (overridden version runs).
  2. Show that v.openTrunk() causes a compile error — the reference type is Vehicle. Comment it out with the error.
  3. Downcasting (explicit): Car c = (Car) v; — now c.openTrunk() works.
  4. Safe downcasting: loop through a Vehicle[] array, use instanceof before casting to call child-specific methods.
  5. Show a ClassCastException: try casting a Motorcycle to Car — write the error as a comment.
--- Upcasting --- Car is driving smoothly at 120 km/h. --- Downcasting --- Opening trunk. --- Safe downcasting with instanceof --- [Car] Toyota at 120 km/h → Opening trunk. [Motorcycle] Kawasaki at 90 km/h → Doing a wheelie! [Truck] Isuzu at 80 km/h → Loading 5.0 tons of cargo.
// v.openTrunk(); → ERROR: cannot find symbol method openTrunk() — reference is Vehicle // Car c = (Car) motorcycle; → ClassCastException: Motorcycle cannot be cast to Car
Key learning: Upcasting (child → parent) is safe and automatic. Downcasting (parent → child) requires an explicit cast and can fail at runtime. Always use instanceof before downcasting to avoid ClassCastException.

10 Putting it all together — Payroll system Mixed

This capstone combines overloading, overriding, interfaces, upcasting, downcasting, and instanceof.

Create an interface Payable with:

  • double calculatePay();
  • default String formatPay() — returns "PHP " + String.format("%.2f", calculatePay())
  • static double calculateTotalPay(Payable[] payables) — sums all pay

Create an interface Reportable with:

  • String generateReport();

Using the Employee, Manager, Developer, and Intern from Exercise 09, make all three child classes implement both Payable and Reportable:

  • calculatePay() — same as getSalary()
  • generateReport() — returns a one-line summary like "Manager Alice Santos | Pay: PHP 95000.00"

In TestPayroll, add the following:

  1. Store all employees in a Payable[] array — use the formatPay() default method.
  2. Store all employees in a Reportable[] array — call generateReport().
  3. Use the static method Payable.calculateTotalPay(...).
  4. Loop through Employee[] and use instanceof Payable to safely cast and access pay.
======================================== PAYROLL REPORT ======================================== --- Pay (via Payable[]) --- PHP 95000.00 PHP 55000.00 PHP 52000.00 PHP 8000.00 --- Reports (via Reportable[]) --- Manager Alice Santos | Pay: PHP 95000.00 Developer Bob Garcia | Pay: PHP 55000.00 Developer Charlie Reyes | Pay: PHP 52000.00 Intern Diana Cruz | Pay: PHP 8000.00 --- Total (via static method) --- Total payroll: PHP 210000.00 ========================================
Key takeaway: This exercise demonstrates all forms of polymorphism in one system: method overriding (each subclass computes pay differently), interface polymorphism (Payable[] and Reportable[] hold different types), default methods (formatPay() inherited by all), static methods (calculateTotalPay), and instanceof + casting for safe type-specific access.
