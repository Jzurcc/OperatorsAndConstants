01 Creating your first object — Car Object

Create a class named Car.

Declare the following instance variables (fields):

  • String brand;
  • String model;
  • int year;
  • String color;

Add a method:

  • public void displayInfo() — prints all fields in a formatted way

Create TestCar with a main method. Use the new keyword to create two Car objects. Assign values to each field using dot notation (e.g. car1.brand = "Toyota"), then call displayInfo() on each.

--- Car 1 --- Brand: Toyota Model: Vios Year: 2023 Color: White --- Car 2 --- Brand: Honda Model: Civic Year: 2024 Color: Black
Key learning: The new keyword creates an object (instance) of a class in memory. Each object has its own copy of the instance variables.

03 Parameterized constructor with this — Student Constructor this

Create a class named Student.

Declare:

  • String name;
  • int studentId;
  • String course;
  • double gpa;

Create a parameterized constructor that accepts all four values. Use the this keyword to distinguish between the parameters and the fields:

  • public Student(String name, int studentId, String course, double gpa)

Add a displayInfo() method. Create TestStudent. Create three Student objects using the constructor and display each.

--- Student 1 --- Name: Alice Reyes ID: 20240001 Course: BSIT GPA: 3.8 --- Student 2 --- Name: Bob Santos ID: 20240002 Course: BSCS GPA: 3.2 --- Student 3 --- Name: Charlie Cruz ID: 20240003 Course: BSIT GPA: 2.9
Key learning: When a parameter has the same name as a field, this.name refers to the field and name refers to the parameter. Without this, Java would assign the parameter to itself.

05 Object with methods — Circle Object Methods

Create a class named Circle.

Declare:

  • double radius;

Create a parameterized constructor that accepts the radius.

Add the following methods:

  • public double getArea() — returns Math.PI * radius * radius
  • public double getCircumference() — returns 2 * Math.PI * radius
  • public double getDiameter() — returns 2 * radius
  • public void displayInfo() — prints all values formatted to 2 decimal places

Create TestCircle. Create two circles with different radii and display info for each.

07 Static field with constructor — Counter Constructor Object

Create a class named Counter.

Declare:

  • static int totalCount = 0; — shared across all objects
  • int id; — unique ID per object
  • String label;

Create a parameterized constructor that accepts label. Inside the constructor:

  1. Increment totalCount by 1.
  2. Assign totalCount to id (so the first object gets id 1, second gets 2, etc.).
  3. Assign the label.

Add a displayInfo() method. Create TestCounter. Create 4 objects and print each, then print the total count.

Created: Item A (ID: 1) Created: Item B (ID: 2) Created: Item C (ID: 3) Created: Item D (ID: 4) Total objects created: 4
Key learning: A static variable belongs to the class, not to individual objects. Every time the constructor runs, it increments the same shared counter.

09 Constructor chaining with this() — Pet Constructor this Overloading

Create a class named Pet.

Declare:

  • String name;
  • String species;
  • int age;
  • String owner;

Create three constructors that chain using this():

  1. public Pet(String name, String species, int age, String owner) — the main constructor, sets all fields
  2. public Pet(String name, String species) — calls this(name, species, 0, "No owner")
  3. public Pet(String name) — calls this(name, "Unknown")

Add a displayInfo() method. Create TestPet. Create one object with each constructor.

--- Pet 1 (full constructor) --- Name: Bantay Species: Dog Age: 3 Owner: Maria Santos --- Pet 2 (name + species) --- Name: Mingming Species: Cat Age: 0 Owner: No owner --- Pet 3 (name only) --- Name: Tweety Species: Unknown Age: 0 Owner: No owner
Key learning: this() calls another constructor in the same class. This avoids repeating assignment logic — simpler constructors delegate to the full one. this() must be the first statement in the constructor.
10 Putting it all together — Classroom Mixed

Create a class named Classroom. This exercise combines objects, constructors, methods, static fields, and arrays.

Declare:

  • static int totalClassrooms = 0;
  • int classroomId;
  • String teacherName;
  • String subject;
  • String[] students; — an array of student names (max 5)
  • int studentCount; — tracks how many students enrolled

Create a constructor that accepts teacherName and subject. Inside:

  1. Increment totalClassrooms and assign it to classroomId.
  2. Initialize the students array with size 5.
  3. Set studentCount to 0.

Add methods:

  • public void enrollStudent(String name) — adds a student if the class is not full (max 5), otherwise prints an error
  • public boolean isFull() — returns true if studentCount equals 5
  • public void displayInfo() — prints classroom ID, teacher, subject, all enrolled students, and count
