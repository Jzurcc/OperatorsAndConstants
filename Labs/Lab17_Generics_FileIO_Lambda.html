08 Built-in functional interfaces Lambda Functional

Package: com.school.lambda

Create a class named BuiltInFunctions.

Inside main, demonstrate the four main built-in functional interfaces from java.util.function:

  1. Predicate<T> — tests a condition, returns boolean:
    • Predicate<Integer> isEven = n -> n % 2 == 0;
    • Predicate<String> isLong = s -> s.length() > 5;
    • Demonstrate .test(), .and(), .or(), .negate()
  2. Function<T, R> — transforms input to output:
    • Function<String, Integer> toLength = s -> s.length();
    • Function<Integer, String> toLabel = n -> "Score: " + n;
    • Demonstrate .apply() and .andThen()
  3. Consumer<T> — accepts input, returns nothing:
    • Consumer<String> shout = s -> System.out.println(s.toUpperCase() + "!");
    • Demonstrate .accept() and .andThen()
  4. Supplier<T> — takes no input, returns a value:
    • Supplier<Double> randomScore = () -> Math.round(Math.random() * 100.0) / 1.0;
    • Demonstrate .get() called multiple times.
--- Predicate --- isEven.test(4): true isEven.test(7): false isEven.and(n > 10).test(12): true isEven.or(n > 10).test(11): true isEven.negate().test(7): true --- Function --- toLength.apply("Hello"): 5 toLabel.apply(95): Score: 95 toLength.andThen(toLabel).apply("Hello"): Score: 5 --- Consumer --- shout.accept("hello"): HELLO! --- Supplier --- randomScore.get(): 73.0 randomScore.get(): 45.0

Note: Supplier output will vary since it's random.
