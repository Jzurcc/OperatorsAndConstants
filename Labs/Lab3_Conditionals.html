Project setup

Follow these steps exactly:

  1. Open IntelliJ IDEA.
  2. Create a new Java project named Conditionals.
  3. Inside the src folder, create a package named com.school.conditionals.
  4. For each exercise below, create the class file specified inside the com.school.conditionals package.
  5. Each class must have a public static void main(String[] args) method that demonstrates the required output.

Exercises
01 Simple if statement if

Create a class named IfExample.

Inside main, declare:

  • int temperature = 38;

Write an if statement: if temperature is greater than 37, print a fever warning. Then, regardless of the condition, always print the temperature.

WARNING: You have a fever! Your temperature is: 38
02 If-else — Even or odd if-else

Create a class named IfElseExample.

Inside main, declare:

  • int number = 45;

Use if-else with the modulus operator (%) to check if the number is even or odd, and print the result.

45 is odd
03 If-else if-else — Score rating if-else if

Create a class named IfElseIfExample.

Inside main, declare:

  • int score = 82;

Use if-else if-else to print a rating based on the score:

  • 90 and above → "Excellent"
  • 80 to 89 → "Very Good"
  • 70 to 79 → "Good"
  • 60 to 69 → "Satisfactory"
  • Below 60 → "Needs Improvement"
Score: 82 Rating: Very Good
04 Nested if — Age and ID check if if-else

Create a class named NestedIfExample.

Inside main, declare:

  • int age = 20;
  • boolean hasID = true;

Write a nested if: first check if age is 18 or above. If yes, check if the person has an ID. Print the appropriate message for each case.

Age: 20 Has ID: true Access granted — welcome!

If age were 16, it should print: "Sorry, you must be 18 or older."

If age were 20 but hasID were false, it should print: "You are old enough but need a valid ID."

05 Switch — Day of the week switch

Create a class named SwitchExample.

Inside main, declare:

  • int day = 3;

Use a switch statement to print the day name: 1 = Monday, 2 = Tuesday, ... 7 = Sunday. Include a default case for invalid numbers.

Day number: 3 Day: Wednesday
06 Switch with String — Day type switch

Create a class named SwitchDayOfWeek.

Inside main, declare:

  • String day = "Saturday";

Use a switch statement on the String to print whether the day is a "Weekday" or "Weekend". Monday through Friday are weekdays; Saturday and Sunday are weekends. Include a default case for invalid input.

Day: Saturday Type: Weekend
07 Grade checker if-else if

Create a class named GradeChecker.

Inside main, declare:

  • double average = 88.5;

Use if-else if-else to assign a letter grade and print it:

  • 97–100 → "1.00"
  • 94–96 → "1.25"
  • 91–93 → "1.50"
  • 88–90 → "1.75"
  • 85–87 → "2.00"
  • 82–84 → "2.25"
  • 79–81 → "2.50"
  • 76–78 → "2.75"
  • 75 → "3.00"
  • Below 75 → "5.00 (Failed)"
Average: 88.5 Grade: 1.75
08 Number classifier if-else if-else if

Create a class named NumberClassifier.

Inside main, declare:

  • int num = -15;

Use conditionals to print all of the following that apply:

  1. Whether the number is positive, negative, or zero
  2. Whether the number is even or odd
  3. Whether the number is a multiple of 5
Number: -15 Sign: Negative Parity: Odd Multiple of 5: Yes
09 Login validator if if-else

Create a class named LoginValidator.

Inside main, declare:

  • String correctUser = "admin";
  • String correctPass = "java123";
  • String inputUser = "admin";
  • String inputPass = "java123";

Use if-else to check if both the username and password match (use .equals() to compare Strings). Print the appropriate message.

Login successful! Welcome, admin.

If the credentials don't match, print: "Login failed. Invalid username or password."

10 Ticket pricing — Putting it all together if-else if switch

Create a class named TicketPricing.

Declare a static final constant:

  • static final double BASE_PRICE = 500.00;

Inside main, declare:

  • int age = 25;
  • String memberType = "Gold";

Compute the ticket price:

  1. Use if-else if-else to apply an age-based discount to BASE_PRICE:
    • Under 12 → 50% off
    • 12 to 17 → 25% off
    • 18 to 59 → no discount
    • 60 and above → 30% off
  2. Use a switch on memberType to apply an additional discount:
    • "Gold" → subtract 100
    • "Silver" → subtract 50
    • "Bronze" → subtract 25
    • default → no additional discount

Print the breakdown:

Age: 25 Member type: Gold Base price: 500.0 Age discount: 0.0 Price after age discount: 500.0 Member discount: 100.0 Final price: 400.0
