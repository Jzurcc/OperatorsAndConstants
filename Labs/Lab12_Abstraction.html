Exercises
01 Abstract class basics — Shape Abstract class

Create an abstract class named Shape with:

  • Field: String color;
  • A constructor that accepts color.
  • Abstract methods (no body): public abstract double getArea(); and public abstract double getPerimeter();
  • A concrete method: public void displayInfo() — prints color, area, and perimeter (calls the abstract methods)

Create Circle extends Shape with field double radius;. Implement both abstract methods.

Create Rectangle extends Shape with fields double width; and double height;. Implement both abstract methods.

Create TestShape. Try to instantiate Shape directly — write the error as a comment. Then create Circle and Rectangle objects and call displayInfo().

// Shape s = new Shape("Red"); → ERROR: Shape is abstract; cannot be instantiated
--- Circle --- Color: Red Area: 78.54 Perimeter: 31.42 --- Rectangle --- Color: Blue Area: 40.00 Perimeter: 26.00
Key learning: An abstract class cannot be instantiated directly. It defines a contract (abstract methods) that child classes must implement. The concrete method displayInfo() works because it calls the implemented versions at runtime.

03 Interface with default method — Loggable Interface default method

Create an interface named Loggable with:

  • void log(String message); — abstract
  • default void logInfo(String message) — prints "[INFO] " + message
  • default void logWarning(String message) — prints "[WARNING] " + message
  • default void logError(String message) — prints "[ERROR] " + message

Create FileLogger that implements Loggable:

  • Implement log() — prints "[FILE] " + message

Create ConsoleLogger that implements Loggable:

  • Implement log() — prints "[CONSOLE] " + message
  • Override logError() — prints "!!! CONSOLE ERROR: " + message + " !!!"

Create TestLoggable. Test both loggers using both the abstract and default methods.

--- FileLogger --- [FILE] System started. [INFO] All services running. [WARNING] Disk space low. [ERROR] Connection timeout. --- ConsoleLogger --- [CONSOLE] System started. [INFO] All services running. [WARNING] Disk space low. !!! CONSOLE ERROR: Connection timeout. !!!
Key learning: default methods in interfaces provide a body that implementing classes inherit automatically. Classes can optionally override them. This lets you add new methods to an interface without breaking existing implementations.
04 Interface with static method — Validator Interface static method

Create an interface named Validator with:

  • boolean validate(String input); — abstract
  • String getValidationType(); — abstract
  • static void printResult(String type, String input, boolean result) — a static helper method that prints: "[type] 'input' → VALID" or "→ INVALID"
  • default void validateAndPrint(String input) — a default method that calls validate() and then calls the static printResult()

Create EmailValidator that implements Validator:

  • validate() — returns true if input contains "@" and "."
  • getValidationType() — returns "Email"

Create AgeValidator that implements Validator:

  • validate() — parse input as int, return true if between 0 and 150. Use try-catch for non-numeric input.
  • getValidationType() — returns "Age"

Create TestValidator. Test both validators using the default validateAndPrint() and also call the static method directly.

--- Email validation --- [Email] 'alice@email.com' → VALID [Email] 'not-an-email' → INVALID [Email] 'bob@test.org' → VALID --- Age validation --- [Age] '25' → VALID [Age] '-5' → INVALID [Age] 'abc' → INVALID [Age] '150' → VALID --- Using static method directly --- [Custom] 'test' → VALID
Key learning: static methods in interfaces belong to the interface itself, not to implementing classes. They are called via Validator.printResult(...) — never through an object. Useful for helper/utility methods related to the interface's purpose.

08 Abstract class with template method — PaymentProcessor Abstract class

Create an abstract class PaymentProcessor with:

  • Fields: String payerName; and double amount;
  • A constructor for both fields.
  • Abstract methods: protected abstract boolean authorize(); and protected abstract void executePayment(); and public abstract String getPaymentMethod();
  • A concrete template method: public final void processPayment() that:
    1. Prints "Processing [method] payment of [amount] for [payerName]..."
    2. Calls authorize() — if false, print error and return
    3. Calls executePayment()
    4. Prints "Payment successful!"

Create CreditCardPayment extends PaymentProcessor:

  • Field: String cardNumber;
  • authorize() — returns true if card number length is 16
  • executePayment() — prints "Charged to card ending in [last 4 digits]."

Create GCashPayment extends PaymentProcessor:

  • Field: String phoneNumber;
  • authorize() — returns true if phone number starts with "09" and length is 11
  • executePayment() — prints "Sent to GCash [phoneNumber]."

Create TestPayment. Test valid and invalid payments.

--- Credit Card Payment --- Processing Credit Card payment of 1500.0 for Alice... Authorizing... Charged to card ending in 5678. Payment successful! --- GCash Payment --- Processing GCash payment of 850.0 for Bob... Authorizing... Sent to GCash 09171234567. Payment successful! --- Invalid Credit Card --- Processing Credit Card payment of 500.0 for Charlie... Authorizing... Authorization failed. Payment cancelled.
Key learning: The template method pattern — processPayment() is a final concrete method that defines the overall steps, while subclasses fill in the details via abstract methods. The flow is fixed; the implementation varies.
09 Polymorphism with interfaces — Billable & Trackable Interface Polymorphism default method static method

Create an interface Billable with:

  • double calculateBill(); — abstract
  • String getBillingType(); — abstract
  • default String formatBill() — returns "[type]: PHP " + String.format("%.2f", calculateBill())
  • static double calculateTax(double amount, double rate) — returns amount * rate

Create an interface Trackable with:

  • int getHoursWorked(); — abstract
  • default String getProductivityLevel() — returns "High" if hours ≥ 160, "Normal" if ≥ 120, otherwise "Low"

Create an abstract class Employee with:

  • Fields: String name; and int id;
  • A constructor and public void displayInfo()

Create FullTimeEmployee extends Employee implements Billable, Trackable:

  • Fields: double monthlySalary; and int hoursWorked;
  • calculateBill() — returns monthlySalary
  • getBillingType() — returns "Monthly Salary"

Create Freelancer extends Employee implements Billable, Trackable:

  • Fields: double hourlyRate; and int hoursWorked;
  • calculateBill() — returns hourlyRate * hoursWorked
  • getBillingType() — returns "Hourly Rate"

Create TestEmployee. Create both, store in a Billable[] array and a Trackable[] array, and loop through each.

--- Billing --- Monthly Salary: PHP 55000.00 Hourly Rate: PHP 48000.00 --- Productivity --- Alice (160 hrs): High Bob (120 hrs): Normal --- Tax calculation (static method) --- Tax on 55000.0 at 12%: 6600.00 Tax on 48000.0 at 10%: 4800.00
10 Putting it all together — School management Mixed

This capstone exercise combines abstract classes, interfaces (with default and static methods), polymorphism, and instanceof.

You will reuse and extend the classes from Exercise 09. In TestEmployee, add the following after your existing code (or create a separate section):

  1. Create an array: Employee[] team = { fullTimeEmployee, freelancer };
  2. Loop through the array. For each employee:
    • Call displayInfo() (inherited from Employee).
    • Use instanceof Billable to check and call formatBill().
    • Use instanceof Trackable to check and call getProductivityLevel().
  3. Compute the total payroll by looping through Billable[] and summing calculateBill().
  4. Compute total tax using Billable.calculateTax(totalPayroll, 0.12).
  5. Print a full summary report.
======================================== TEAM SUMMARY REPORT ======================================== [ID: 1] Alice Santos Type: Full-Time Employee Monthly Salary: PHP 55000.00 Hours: 160 | Productivity: High [ID: 2] Bob Garcia Type: Freelancer Hourly Rate: PHP 400.00 x 120 hrs = PHP 48000.00 Hours: 120 | Productivity: Normal ======================================== Total payroll: PHP 103000.00 Tax (12%): PHP 12360.00 Net payroll: PHP 90640.00 ========================================
Key takeaway: This exercise shows how abstract classes (shared data + structure), interfaces (shared behavior contracts), default methods (reusable implementations), static methods (utility functions), and polymorphism (one array, different types) all work together in a real-world scenario.
